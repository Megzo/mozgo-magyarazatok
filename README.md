# Mozgó magyarázatok

Öt tantárgy, öt téma – lépésről lépésre animált, interaktív leckék az oktatáshoz.

**Megnyitás:** https://megzo.github.io/mozgo-magyarazatok/

| Tantárgy | Téma |
|---|---|
| Történelem | A magyarok vándorlása az őshazától a Kárpát-medencéig |
| Kémia | A maghasadás működése |
| Fizika | A kompresszoros hűtés elve |
| Matematika | A kör területe és a π |
| Informatika | Kézzel írt számjegyek felismerése neurális hálóval (MNIST) |

Léptetés: <kbd>←</kbd> <kbd>→</kbd> · <kbd>R</kbd> újrajátszás · <kbd>F</kbd> teljes képernyő.
Teljesen statikus és offline is működik: letöltés után az `index.html` dupla kattintással megnyitható.

Források: térkép – [Natural Earth](https://www.naturalearthdata.com/) (közkincs); kézírás-adatok – MNIST;
betűtípusok – Fraunces, Bricolage Grotesque, JetBrains Mono (SIL Open Font License).
